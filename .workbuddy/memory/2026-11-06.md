## 目录二级分组：二次点击收不起来

- 根因：`.toc-lv1` 的 click 只调 `showCh(dataset.ch)`，而 `showCh` 里是
  `g.classList.toggle('open', a.dataset.ch === id)` —— 点当前章节等于「再展开一次」，
  永远收不起来；分组本身根本没有 toggle 逻辑。
- 修法：click 里先判断 `a.dataset.ch === 当前 .chapter.on 的 id`，是就只 `classList.toggle('open')`
  并同步 `aria-expanded`，不再走 `showCh`（否则还会顺带 `scrollTo(0)`）。
- 动画：`display:none` 无法过渡，改成 `grid-template-rows: 0fr → 1fr` + 内层
  `.toc-subs-inner{min-height:0;overflow:hidden}`。代价是要在 8 个 `.toc-subs` 里加一层 wrapper
  （否则多个锚点会各占一行，0fr 只作用于第一行）。
- 收起后子项还能被 Tab 聚焦，用 `visibility:hidden` + `transition: visibility 0s linear .26s`
  延迟到动画结束再生效解决。
- `spy()` 里目录跟随滚动那段要加 `grp.classList.contains('open')` 判断：收起时链接
  `getBoundingClientRect()` 是全 0，会把 `toc.scrollTop` 一路减到顶。

### 无头环境验动画的老坑（重要）

`--virtual-time-budget` 下 **CSS 过渡的时钟不走**：`getAnimations()` 能拿到
`playState=running` 的 transition，但 `currentTime` 永远是 0，`transitionend` 不触发，
量到的 `height` 停在起始值——不要据此判断"动画没生效"。

绕法：拿到 `p.getAnimations()` 后 `pause()`，手动把 `currentTime` 设成 65/130/195/259 再量高度，
得到 170→130→38→7→0 就说明属性真的能插值。截图同理，seek 到 120ms 可以拍到中间帧。

### 第六轮：放大后点不到 X / 登录态改 localStorage

- 原图查看器 `.ws-lightbox` 里 DOM 顺序是 `<button.lb-close>` 然后 `<img>`。图片放大后带
  `transform`，会自成层叠上下文并按 DOM 顺序排在按钮之后，**把 38px 的圆钮整个盖住**，
  点下去 target 是 img，而关闭逻辑只认 `e.target === lb` 或 `.lb-close`，所以关不掉。
  修法：`.lb-close { z-index: 8 }`（高于 `.zoom-reset` 的 7、`.zoom-hint` 的 6）。
  对照实测：去 z-index → `elementFromPoint` 命中 IMG、`closed=false`；加 z-index → 命中
  `lb-close`、`closed=true`。
- 登录态 `sessionStorage` → `localStorage`（key 仍是 `hzz_session`）。写入时顺手清旧的
  sessionStorage 那份；读取优先 localStorage，读不到再回退 sessionStorage（兼容老会话）。
- 违反"不自动清"的地方一起改了：`loadChiefWater` 里 401 原本会 `backToLogin()` 直接清登录态，
  现在只 toast + 结果区提示，不清。清空只发生在用户点顶栏"退出"。
- 无头验证踩坑：`--virtual-time-budget` 会把 setTimeout 快进，页面还没 load 完就跑到断言了，
  必须用 `readyState==='complete'` + 轮询，别用固定延时。另外 iframe 设成同一个 URL+hash
  不会触发重载（测不出刷新后的状态），加个 `?r=1` 强制重新导航。
  另外 login.html 引了 3MB 的 login-back.png，`readyState` 可能长期停在 loading，
  断言条件别硬等 complete，等目标元素出现就行。
